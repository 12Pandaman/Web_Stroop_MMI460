### 🌐 1. ภาษาหลักในการพัฒนา (Core Languages)

#### 1️⃣ **HTML5 (HyperText Markup Language)** - โครงสร้างของเว็บไซต์
* **ไฟล์หลัก**: [`index.html`](file:///c:/Users/User/Downloads/test%20stroop/index.html)
* **หน้าที่**: กำหนดโครงสร้างเนื้อหาของเว็บทั้งหมดแบบ Semantic HTML5 
* **ส่วนประกอบสำคัญ**:
  * **Header**: แสดงตราสัญลักษณ์ ชื่อโปรแกรม ปุ่มเปิด/ปิดเสียง และปุ่มดูประวัติ
  * **Screen 1 (Setup Screen)**: ฟอร์มตั้งค่าชื่อผู้ทดสอบ, จำนวนข้อ, และการเลือกโหมด 4 เงื่อนไข
  * **Screen 2 (Test Arena)**: แถบแสดงสถานะ HUD (เวลา Real-time, คะแนน, ข้อปัจจุบัน, แท็กเงื่อนไข), พื้นที่แสดงตัวอักษรโจทย์ (Stimulus Box), และตารางปุ่มกดตัวเลือกตอบ
  * **Screen 3 (Results Dashboard)**: การ์ดสรุปผลสถิติภาพรวม, ตารางเปรียบเทียบ 4 เงื่อนไข, ตารางบันทึกรายข้อ, และปุ่มส่งออก CSV/JSON
  * **Modal Window**: หน้าต่างกล่องโต้ตอบแสดงประวัติผู้ทดสอบรายคน

#### 2️⃣ **CSS3 (Cascading Style Sheets)** - การออกแบบและความสวยงาม (Styling & Design)
* **ไฟล์หลัก**: [`style.css`](file:///c:/Users/User/Downloads/test%20stroop/style.css)
* **หน้าที่**: ควบคุมความสวยงาม การจัดวางตำแหน่ง (Layout) และเอฟเฟกต์การเคลื่อนไหว
* **เทคนิคพิเศษที่ใช้**:
  * **CSS Custom Properties (Variables)**: ใช้ตัวแปรเก็บโทนสีหลัก เช่น `--bg-dark`, `--primary-glow`, `--color-red` เพื่อความสม่ำเสมอของธีม
  * **Glassmorphism Design**: ใช้ `backdrop-filter: blur(16px)` ร่วมกับสีพื้นหลังโปร่งแสง (RGBA) และเส้นขอบเรืองแสง ให้ความรู้สึกหรูหรา ทันสมัย
  * **Flexbox & CSS Grid**: จัดวางโครงสร้างให้รองรับทุกขนาดหน้าจอ (Responsive Design) ทั้งคอมพิวเตอร์และสมาร์ตโฟน
  * **Keyframe Animations**: สร้างอนิเมชันลูกกลมเรืองแสงลอยในพื้นหลัง (`@keyframes floatOrb`) และเอฟเฟกต์การกดปุ่ม/Hover

#### 3️⃣ **JavaScript ES6+ (Vanilla JavaScript)** - สมองและระบบการทำงาน (Logic & Engine)
* **ไฟล์หลัก**: [`app.js`](file:///c:/Users/User/Downloads/test%20stroop/app.js)
* **หน้าที่**: ควบคุมอัลกอริทึมการทำงาน สถิติ และระบบโต้ตอบทั้งหมด โดยไม่ใช้ Framework ภายนอก (Pure JavaScript) เพื่อความเร็วสูงสุด
* **Web APIs ภายใน JavaScript ที่นำมาใช้**:
  1. **High-Precision Timing API (`performance.now()`)**: 
     * ใช้จับเวลาปฏิกิริยาตั้งแต่เริ่มแสดงโจทย์จนผู้ใช้กดตอบ โดยมีความละเอียดสูงถึงระดับ **มิลลิวินาที (ms)** และนำมาทศนิยมเป็นวินาที (`1.234 s`)
  2. **Web Audio API (`AudioContext`, `OscillatorNode`)**:
     * สร้างเสียงเอฟเฟกต์ตอบถูก (Sound Chime) และตอบผิด (Low Buzz) ขึ้นมาสดๆ ด้วยโค้ดสัญญาณเสียงดิจิทัล โดยไม่ต้องโหลดไฟล์ MP3 ให้หนักเครื่อง
  3. **Web Storage API (`localStorage`)**:
     * บันทึกประวัติการทดสอบของผู้ทดสอบทุกคนลงในหน่วยความจำของเบราว์เซอร์ (`stroop_pro_history`) เพื่อให้เปิดดูข้อมูลย้อนหลังได้ตลอดเวลา
  4. **DOM & Keyboard Event Listeners**:
     * สลับหน้าจออัตโนมัติ สลับภาษาปุ่มตอบ (ไทย/อังกฤษ) ตามเงื่อนไขข้อสอบ และรองรับคีย์บอร์ดทางลัด (ปุ่ม `1`, `2`, `3`, `4`)
  5. **Blob & Object URL API (`new Blob()`)**:
     * แปลงข้อมูลชุดทดสอบเป็นไฟล์ **.CSV** และ **.JSON** ให้ผู้ใช้กดดาวน์โหลดลงเครื่องได้ทันที
